# Semana 03 — IA na Rotina: Automação Inteligente

**Formação:** IA Aplicada | {reprograma}  
**Status:** ✅ Concluída

## 🎯 Objetivo

Explorar a automação de processos utilizando ferramentas no-code e Inteligência Artificial, integrando diferentes aplicações para reduzir tarefas manuais.

## 🛠️ Ferramentas utilizadas

- **Make:** criação e organização do fluxo de automação.
- **Google Forms:** coleta de informações.
- **Make AI Toolkit:** processamento de texto com IA.
- **Google Docs:** geração de documentos.
- **Google Sheets:** registro das informações.
- **Gmail:** envio de mensagens por e-mail.

## 💻 Atividade prática — Automação de mentoria

Foi desenvolvido um cenário de automação baseado em um formulário de inscrição para mentoria, denominado **Mentoria com a Dani**.

O fluxo foi estruturado para receber respostas, processar informações com IA, criar documentos, registrar dados em planilha e encaminhar mensagens conforme condições estabelecidas.

## 🔄 Etapas da automação

1. Recebimento das respostas pelo Google Forms.
2. Resumo das informações utilizando o Make AI Toolkit.
3. Tradução do texto utilizando o Make AI Toolkit.
4. Criação de documento no Google Docs a partir de um modelo.
5. Registro das informações no Google Sheets.
6. Aplicação de condição lógica (if-else) para envio de e-mail pelo Gmail.

## ✅ Resultado da atividade

O cenário desenvolvido no Make foi **executado com sucesso**, conforme relatado pela participante. A imagem do fluxo registra a integração entre os serviços e a ramificação condicional.

**Principais resultados:**

- Construção e execução de um cenário de automação no-code.
- Integração entre diferentes ferramentas.
- Utilização de IA para processamento de textos.
- Aplicação de condições lógicas no fluxo.
- Validação prática do funcionamento da automação.

## 💡 Aprendizados

Com essa atividade, compreendi como a automação pode conectar diferentes ferramentas, reduzir atividades manuais e tornar processos mais eficientes.

A experiência contribuiu para o desenvolvimento das minhas habilidades em integração de sistemas, lógica de automação e aplicação prática de Inteligência Artificial.
