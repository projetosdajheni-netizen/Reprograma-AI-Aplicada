# Semana 06 — Comunicação e Narrativa

**Formação:** IA Aplicada | {reprograma}  
**Status:** ✅ Atividade desenvolvida

## 🎯 Objetivo

Aprender a transformar dados em mensagens claras e estratégicas, selecionando visualizações adequadas para apoiar a compreensão e a tomada de decisão.

## 💻 Projeto — Meus Dados no Gráfico Certo

A atividade deu continuidade ao desafio da Semana 05, sobre a possível descontinuação de uma linha municipal de ônibus.

O objetivo foi selecionar gráficos capazes de comunicar diferentes aspectos do problema, sem misturar indicadores que representam informações distintas.

## 📊 Desenvolvimento da atividade

Foram trabalhadas quatro perguntas:

1. Como a ocupação da linha avaliada se compara à das linhas próximas?
2. Como o custo por passageiro se compara à média municipal?
3. Qual é a composição do perfil de usuários?
4. Como a ocupação média se compara a um possível pico de demanda no horário crítico?

Para cada pergunta, foram identificados o tipo de análise e a visualização mais adequada.

## 🎤 Comunicação e storytelling

Foi desenvolvido um mini-pitch de aproximadamente 60 segundos, apresentando os principais indicadores, as limitações dos dados e a necessidade de investigar a demanda por horário antes de decidir pelo cancelamento.

## 📝 Feedback e desenvolvimento

A mentora Karina Kaori destacou positivamente o raciocínio crítico utilizado na análise.

Como oportunidade de melhoria, orientou separar indicadores de naturezas diferentes em gráficos específicos, evitando comparações visualmente enganosas.

Esse feedback reforçou a importância de utilizar uma visualização para cada mensagem central.

## 💡 Competências desenvolvidas

- Data Storytelling.
- Visualização de dados.
- Comunicação estratégica.
- Escolha de gráficos conforme o objetivo.
- Interpretação de indicadores.
- Construção de mini-pitch.
- Análise crítica e melhoria a partir de feedback.

## 📚 Aprendizados

Compreendi que uma análise pode estar bem fundamentada e, ainda assim, perder clareza quando os dados são apresentados de maneira inadequada.

O desafio reforçou que comunicar dados exige tanto cuidado quanto analisá-los.

**Um gráfico eficiente não apenas apresenta números: ele ajuda o público a compreender a mensagem correta.**
