# Semana 05 — Dados como Insumo para Decisão

**Formação:** IA Aplicada | {reprograma}  
**Status:** ✅ Concluída

## 🎯 Objetivo

Desenvolver o raciocínio analítico para interpretar dados, identificar informações ausentes e apoiar decisões estratégicas com responsabilidade.

## 💻 Desafio prático — Viabilidade de uma linha de ônibus

O desafio consistiu em avaliar a proposta de cancelamento de uma linha municipal de ônibus com déficit operacional, considerando os impactos financeiros, operacionais e sociais.

A análise exigiu equilibrar a necessidade de otimização de recursos com a segurança e a mobilidade da população.

## 📊 Indicadores analisados

| Indicador | Resultado |
|---|---|
| Passageiros por dia | 760 |
| Custo operacional mensal | R$ 41.000 |
| Receita tarifária mensal | R$ 25.000 |
| Déficit mensal | R$ 16.000 |
| Ocupação média | 31% |
| Intervalo médio | 35 minutos |
| Custo por passageiro | 74% acima da média municipal |
| Usuários sem alternativa | 28% |

## 🔎 Desenvolvimento da atividade

Foram realizadas as seguintes etapas:

1. Separação entre fatos e interpretações.
2. Identificação das limitações dos dados disponíveis.
3. Formulação de perguntas para reduzir incertezas.
4. Análise crítica da proposta de cancelamento.
5. Construção de um prompt de IA com persona especializada em infraestrutura e transportes.
6. Elaboração de dois gráficos para visualizar indicadores.
7. Organização de uma mini base de dados.
8. Aplicação dos conceitos de dado, informação, conhecimento e sabedoria (DIKW).

## 🤖 Aplicação de Inteligência Artificial

Foi elaborado um prompt orientando a IA a atuar como um administrador sênior de infraestrutura de uma companhia municipal de ônibus.

A proposta foi estruturar uma análise estratégica, considerando:

- Indicadores financeiros e operacionais.
- Segurança dos passageiros.
- Dados ausentes.
- Riscos da realocação dos veículos.
- Alternativas ao cancelamento imediato.

Como resultado, foi produzido um relatório executivo com indicadores, gráficos, análise de riscos e recomendações.

## 📌 Conclusão da análise

A recomendação foi não decidir pelo cancelamento imediato da linha apenas com os indicadores apresentados.

Embora o déficit operacional seja relevante, os dados não demonstram como os passageiros estão distribuídos ao longo do dia nem se as alternativas propostas atenderiam com segurança a população.

A decisão responsável exige informações complementares e avaliação dos impactos sociais.

## 💡 Competências desenvolvidas

- Análise crítica de dados.
- Interpretação de indicadores.
- Visualização de dados.
- Estruturação de bases de dados.
- Prompt Engineering aplicado à análise.
- Identificação de riscos e incertezas.
- Tomada de decisão baseada em evidências.

## 📚 Aprendizados

A principal aprendizagem foi compreender que dados isolados não representam necessariamente todo o contexto de um problema.

Uma decisão estratégica precisa considerar a qualidade das informações, suas limitações e as consequências para as pessoas envolvidas.

**Nem sempre decidir rapidamente significa decidir corretamente.**
